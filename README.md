# 哔哩哔哩直播活动亲密度计算器

AstrBot 聊天插件。根据电池预算规划猫粮、粉丝手幅、亲密之旅、身份订单与盲盒，并返回预计亲密度区间。

## 安装

将整个 `astrbot_plugin_bilibili_intimacy` 目录放到 AstrBot 的 `data/plugins/` 目录，然后在 WebUI 插件管理中重载或启用该插件。

本插件不依赖第三方 Python 包。

## 使用

```text
/电池收益 1000
/电池收益 5639 鲜食 不抢首赠
/电池收益 38064 鲜食 提醒
/电池收益帮助
```

可用选项：

- `普通`、`冻干`、`鲜食`、`自动`：指定或自动选择猫粮品质。
- `提醒`：加入主播提醒回礼计划。
- `不抢首赠`：粉丝手幅不优先占用每日首赠。
- `不跑旅程`：不安排亲密之旅。
- `确定性`：不分配盲盒，全部使用确定性赠礼。

## 计算说明

基础规则来自活动规则附件；盲盒契约期望、主播榜亲密值以及部分投入倍率由用户提供的同款计算器截图反推拟合，因此输出适用于预算规划，不保证等同活动后台最终结算。
