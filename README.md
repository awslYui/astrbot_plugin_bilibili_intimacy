# 哔哩哔哩直播活动亲密度计算器

## 版本

当前版本：`1.2.1`（首赠倍率按基础、活动首赠、奖励日与大航海加成相加计算；默认自动比较猫粮与每日首赠礼物）。

AstrBot 聊天插件。根据电池预算规划猫粮、粉丝手幅、亲密之旅、身份订单与盲盒，并返回预计亲密度区间。

## 安装

将整个 `astrbot_plugin_bilibili_intimacy` 目录放到 AstrBot 的 `data/plugins/` 目录，然后在 WebUI 插件管理中重载或启用该插件。

本插件不依赖第三方 Python 包。

## 使用

```text
/电池收益 1000
/电池收益 5639 鲜食 不抢首赠
/电池收益 38064 鲜食 提醒
/电池收益 220000 总督 首赠3
/电池收益帮助
```

不指定礼物时会自动比较粉丝手幅、舰长、提督、总督与猫粮方案，采用预计亲密度最高的组合。控制台可设置“自动收益优化时使用的每日首赠倍率”（默认 `3`）；指令中的 `首赠1`、`首赠2`、`首赠3` 会覆盖该设置。

可用选项：

- `普通`、`冻干`、`鲜食`、`自动`：指定或自动选择猫粮品质。
- `舰长`、`提督`、`总督`：将该礼物作为每天第一笔礼物。总督按 ¥19,998，即 199,980 电池计算。
- `首赠1`、`首赠2`、`首赠3`：指定当天页面显示的首赠倍率。
- `提醒`：加入主播提醒回礼计划。
- `不抢首赠`：粉丝手幅不优先占用每日首赠。
- `不跑旅程`：不安排亲密之旅。
- `确定性`：不分配盲盒，全部使用确定性赠礼。

## 计算说明

基础规则来自活动规则附件；盲盒契约期望、主播榜亲密值以及部分投入倍率由用户提供的同款计算器截图反推拟合，因此输出适用于预算规划，不保证等同活动后台最终结算。
